# Evidence

This directory is reserved for reproducible evidence generated by tests, live Gemini calls, Firestore integration, Cloud Run deployment and the final hackathon demo.

## Rules

```text
TEST_WRITTEN != TEST_EXECUTED
MODEL_CONFIGURED != MODEL_CALLED
FIRESTORE_ADAPTER_PRESENT != FIRESTORE_USED
CLOUD_RUN_TARGET_DECLARED != CLOUD_RUN_DEPLOYED
SCREENSHOT != COMPLETE_PROOF
```

Evidence entries should bind to an exact repository commit whenever possible and include the command/run that produced them.

At initialization no execution evidence is claimed here.
